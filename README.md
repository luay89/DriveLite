# DriveLite Launcher

واجهة رئيسية خفيفة لشاشات السيارات بنظام Android 12 فما فوق (مُحسّنة لدقة 1024×600).

- **بدون أي مكتبات** (لا AndroidX ولا Compose) → APK صغير جدًا وتشغيل سريع.
- **بدون صلاحيات** وبدون Root وبدون خدمات خلفية.
- الساعة والتاريخ عبر `TextClock` من النظام (تحديث مرة في الدقيقة فقط).
- تحميل قائمة التطبيقات والأيقونات في خيط خلفي واحد مع ذاكرة مؤقتة محدودة → لا تعليق.
- ستة أزرار: الخرائط، الراديو، الهاتف، الموسيقى، التطبيقات، الإعدادات.
- أربعة ثيمات (Midnight, Graphite, Ocean, Amber) تُحفظ محليًا.
- **ضغطة مطولة** على الخرائط/الراديو/الهاتف/الموسيقى لاختيار أي تطبيق (مهم لتطبيق راديو الشركة المصنعة).
- عند عدم إيجاد تطبيق مناسب تظهر رسالة واضحة مع خيار الاختيار اليدوي.
- تعيين DriveLite واجهة رئيسية عبر نافذة النظام الرسمية (RoleManager)، وزر **العودة إلى الواجهة الأصلية**.
- واجهة عربية/إنجليزية حسب لغة الجهاز.

## البناء عبر GitHub Actions
1. ارفع المجلد إلى المستودع `luay89/DriveLite` (فرع `main`).
2. تبويب **Actions** ← `Build APK` يعمل تلقائيًا (أو اضغط *Run workflow*).
3. بعد النجاح نزّل Artifact باسم **DriveLite-apk** وفيه:
   - `DriveLite-release.apk` ← **هذا للاستخدام اليومي** (أصغر وأسرع).
   - `DriveLite-debug.apk` ← للتشخيص.
   - `SHA256SUMS.txt`.

الـ Workflow يستخدم **JDK 21** صراحةً، ويشغّل `testDebugUnitTest` و`lintDebug` و`assembleDebug` و`assembleRelease`، ثم يتحقق من كل APK (`aapt2 dump badging` و`apksigner verify`) ويحسب SHA-256. تقرير lint يُرفع في Artifact باسم `reports`.

## البناء محليًا / Codespaces
```bash
./gradlew testDebugUnitTest lintDebug assembleRelease
```
يتطلب JDK 21 وAndroid SDK (platform 34).

## التثبيت على الشاشة
1. **احذف أي نسخة DriveLite قديمة أولًا** — النسخة الجديدة موقّعة بمفتاح مختلف، ولن تُثبَّت فوق القديمة.
2. انسخ `DriveLite-release.apk` إلى الشاشة وثبّته (فعّل «مصادر غير معروفة» لمدير الملفات إن طُلب).
3. افتح DriveLite ← اضغط الشريط «اضغط لجعل DriveLite الواجهة الرئيسية» ← وافق.

### لماذا ظهرت سابقًا رسالة "There was a problem parsing the package"؟
أكثر الأسباب شيوعًا، وكلها معالَجة هنا:
| السبب | المعالجة في هذا المشروع |
|---|---|
| غياب `android:exported` في Activity لها intent-filter (إلزامي منذ Android 12) | موجود صراحةً لكل Activity |
| `minSdk` أعلى من إصدار الجهاز | `minSdk = 31` (Android 12) |
| APK غير موقّع أو نسخة testOnly من زر Run | توقيع ثابت v1+v2+v3، والبناء عبر Gradle وليس Run |
| ملف تالف/ناقص أثناء النقل | قارن SHA-256 بعد النقل |

إن استمرت المشكلة، أرسل لي ناتج خطوة *Verify APKs* من GitHub Actions.

## المفتاح `keystore/drivelite.jks`
مفتاح توقيع ثابت داخل المستودع حتى تُثبَّت كل نسخة جديدة فوق السابقة دون حذف. مناسب للاستخدام الشخصي فقط — **ليس لـ Google Play**.
